# 노인 정서 동반자 AI 앱
CalmChat은 노인분들의 정서적 안정과 건강한 일상 유지를 돕기 위해 개발된 AI 기반 정서 동반자 애플리케이션입니다.
사용자 친화적인 인터페이스를 통해 AI 챗봇과의 자연스러운 대화를 제공하며, 대화 내용을 분석하여 사용자의 감정 상태를 파악하고 필요한 경우 적절한 케어 개입을 지원합니다. 또한, 가족의 목소리를 합성하여 더욱 친밀한 소통 경험을 제공하는 기능도 포함하고 있습니다.
